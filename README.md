## 🎧 About Jahan Music

**Jahan Music** is a music player project focused on creating a simple, convenient, and enjoyable music listening experience.

The goal is to develop a clean and organized music application that makes listening to and managing music easier.

More than just a playback application, Jahan Music is an evolving project with a focus on usability, design, and continuous improvement.

> Music is not just something you hear. It's something you experience.

## 📥 Installation

### 01. Clone the repository

```bash
git clone https://github.com/M-JAHANARA/music_player.git
```

### 02. Open the project

```bash
cd music_player
```

### 03. Open in Android Studio

1. Launch Android Studio.
2. Select **Open**.
3. Choose the cloned `music_player` directory.
4. Allow Gradle synchronization to complete, if applicable.
5. Build and run the project using a compatible Android device or emulator.
